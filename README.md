# CHIP for AbanteCart

This module adds CHIP payment method option to your AbanteCart shop.

## Installation

> **⚠️ Always download from the [Releases page](https://github.com/CHIPAsia/chip-for-abantecart/releases/latest/download/chip-abantecart.zip), not the "Download ZIP" button on the repository.** The release package is the verified, versioned install file. Downloading from `main` may pull in unreleased changes.

1. [Download the latest release](https://github.com/CHIPAsia/chip-for-abantecart/releases/latest/download/chip-abantecart.zip).
2. Log in to your AbanteCart admin panel.
3. Navigate to **"Extensions"** > **"Install Extension"**, then click the **"Extension Upload"** tab to upload the zip file.

## Configuration

Set the **Brand ID** and **Secret Key** in the plugin settings.

Optionally, under the **Payment Methods** multiselect, choose which CHIP payment methods to offer at checkout. Supported methods:

- FPX / FPX B2B1
- Cards (Visa, Mastercard, Maestro)
- Atome, GrabPay, Maybank QR, ShopeePay, Touch 'n Go eWallet
- DuitNow QR (resolves to `dnqr` when the merchant has it)
- Crypto Coin
